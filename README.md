# CleanCity SL
CleanCity SL is a digital public good platform designed to improve waste management in Sierra Leone.
## Problem
Poor waste disposal contributes to:
- blocked drainage systems
- flooding
- poor sanitation
- disease outbreaks
## Solution
CleanCity SL allows users to:
- Report waste issues
- Schedule waste pickups
- Find nearby disposal points
## Technologies Used
- HTML5
- CSS3
